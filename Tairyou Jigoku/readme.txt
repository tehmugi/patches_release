how to use:
-----------
- get your copy of tairyou jigoku (.bin file CRC32: 62F40224)
- name the .bin to SLPS20488.bin
- put SLPS20488.bin into the same folder with patchme.bat, xdelta.exe and tairyou.jigoku.eng.v1.00.xdelta
- run patchme.bat
- run check_result.sfv to verify that the patching was succesful. (patched .bin file CRC32 should be 37A00CAE)
- .cue file is included with the patch and does not need to be separately made.
- burn to a CD or load in emulator to play the game.
